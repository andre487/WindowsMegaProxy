# v0.3.1

## English

- Installer and UI: the uninstaller now offers two explicit choices — keep profiles/rules/settings (default) or permanently delete the selected installation’s data; choosing deletion sets the new remove-all action (or RemoveData=1 in the UI) and other users’ personal installations and DEV data are not removed.
- Command-line / bundle behavior: the setup helper accepts a new remove-all action and passes a RemovalAction variable to the bundle; remove-all requires an explicit uninstall confirmation and will invoke data deletion for the selected scope.
- Full-removal semantics: when delete-data is selected the uninstaller deletes the installation’s application data (per-user or system), removes launcher and protected runtime folders, and cleans local application data entries for the chosen scope.
- Safety checks: data deletion validates the whole target tree before removing files, refuses to operate on root paths, and rejects reparse points/junctions so the removal does not follow user-created links.
- Installer UI and logs: the installer UI shows a live, read-only installation log that follows the engine log, limits kept log text to a bounded size, and displays a WPF progress bar that switches from an indeterminate animation to reported percentages when progress values are provided.
- Error reporting and rollback: installation now reports which file could not be written when a write fails, attempts rollback, and will surface both the original error and rollback error together if rollback also fails.
- Network diagnostics: connection checks now query an IP reputation provider (ProxyCheck) and surface a short reputation string in the Diagnostics panel before running a speed test; reputation answers are cached and a reputation provider outage yields the non-fatal text “Reputation request failed”.
- Defaults and UX: fresh personal installs use concrete defaults (startup mode defaults to manual and automatic updates default to enabled) and uninstall keeps data by default; full deletion requires explicit selection and the documentation advises exporting configuration beforehand.

## Русский

- Установщик и интерфейс: при удалении теперь можно выбрать одно из двух действий — сохранить профили/правила/настройки (по умолчанию) или безвозвратно удалить данные выбранной установки; при выборе удаления устанавливается новое действие remove-all (или RemoveData=1 в UI), личные установки других пользователей и DEV‑данные не удаляются.
- Командная строка/пакет: помощник установки поддерживает новый action remove-all и передаёт переменную RemovalAction в бандл; remove-all требует явного подтверждения деинсталляции и запускает удаление данных для выбранной области установки.
- Поведение полного удаления: при выборе удаления данных деинсталлятор удаляет папки с данными приложения для выбранной области (пользовательской или системной), удаляет лаунчер и защищённые runtime‑папки и очищает соответствующие записи в LocalAppData для этой области.
- Меры безопасности: удаление данных предварительно проверяет всё дерево файлов, запрещает операцию для корневых путей и не следует за точками переадресации/junction, чтобы не удалять содержимое через пользовательские ссылки.
- UI установщика и логи: интерфейс установщика показывает живой, доступный для чтения лог установки, автоматически следует за логом движка, ограничивает объём хранимого текста лога и отображает WPF‑полосу прогресса, которая переключается с анимации ожидания на процентный индикатор при наличии значения прогресса.
- Отчёт об ошибках и откат: при невозможности записать файл установка теперь сообщает, какой файл не удалось установить, пытается выполнить откат и при провале отката показывает оба сообщения об ошибке вместе.
- Диагностика сети: проверка соединения теперь включает запрос репутации IP (ProxyCheck) и показывает короткую строку репутации в панели диагностики до запуска speed‑test; результаты репутации кэшируются, а при недоступности провайдера репутации отображается «Reputation request failed» и сама проверка остаётся успешной.
- Значения по умолчанию и удобство: свежая личная установка получает конкретные значения по умолчанию (режим запуска — manual, автообновления включены), деинсталляция по умолчанию сохраняет данные, а полное удаление требует явного выбора — при необходимости экспортируйте конфигурацию заранее.

# v0.0.1

## English

- Initial Windows preview: shipped a Windows-focused client layout (WPF UI, service broker, runtime/controller, launcher) with per-user and machine installation modes and a protected per-version layout under Program Files.
- Installer and install modes: added an Inno-based installer that supports manual/login/service modes, silent /MODE installs, preserves personal/global settings on upgrade, downloads the .NET Desktop Runtime when missing, and retains previous version for rollback; the installer EXE is committed but not Authenticode-signed in this preview.
- Signed update manifests: packaging produces update-manifest.json and update-manifest.sig (Ed25519) and embeds update-public-key.txt; packaging refuses production publishes without UPDATE_SIGNING_KEY or from a dirty checkout, and installers are verified against signed manifests before install.
- Release automation and CI: GitHub workflows provide windows CI (windows-tests) and release pipelines that validate tag format, require a successful main CI run, optionally re-use prior artifacts, build installers (when signing secret present), run VirusTotal scans (VIRUSTOTAL_API_KEY required) and preserve partial scan reports; prepare-release can generate bilingual (en/ru) draft notes using OPENAI_API_KEY when supplied.
- Build/test tooling and wrappers: added script wrappers (build.cmd, build-installer.cmd, install.cmd, tools.cmd and others) and CI test commands (engine/h3/ui/ssh tests) that the Windows CI expects to run on windows-2025 with the uv/python toolchain and .NET SDK.
- Import/export and limits: UI supports import/export of MegaProxy JSON v1–8 and common proxy lists, defaults to excluding passwords/private keys, and enforces limits visible to users (max 1,000 profiles/rules, local settings ≤8 MiB, export ≤4 MiB, private key ≤64 KiB).
- Runtime/network capabilities and limits: supports HTTPS, SOCKS5, MASQUE (requires HTTP/3), and SSH (TCP-only); HTTP/3 is experimental and hidden when unsupported, MASQUE requires QUIC/HTTP/3, and SSH Jump and passphrase-protected SSH keys are explicitly not yet supported for Windows.
- Assets and localization: includes Russian UI strings (assets/strings.json), profile color palette, 257 country flag entries, icons/branding SVGs, and an update public key value committed in assets/update-public-key.txt for updater pinning.
- Tests and smoke checks: added unit tests, UI/integration checks and smoke scripts (tests/WindowsMegaProxy.UiChecks, installer_smoke.py, dev_mode_smoke.py) and CI artifacts uploading (screenshots, logs, test reports); many smoke tests intentionally avoid activating TUN or system drivers and require disposable Windows VMs for full installer/driver validation.

## Русский

- Начальный предварительный релиз для Windows: добавлена Windows-ориентированная структура (WPF UI, брокер службы, runtime/контроллер, лаунчер) с поддержкой установки в режиме пользователя и системы и с защищённой версионной структурой в Program Files.
- Установщик и режимы установки: добавлен Inno Setup установщик с режимами manual/login/service, поддержкой тихой установки (/MODE), сохранением персональных и глобальных настроек при обновлении, докачкой .NET Desktop Runtime при отсутствии и сохранением предыдущей версии для отката; инсталлятор включён в артефакты, но в этом превью не подписан Authenticode.
- Подписанные манифесты обновлений: упаковка генерирует update-manifest.json и update-manifest.sig (Ed25519) и коммитит update-public-key.txt; упаковка отказывается публиковать production-релиз без UPDATE_SIGNING_KEY или при грязной рабочей копии, а установщики проверяются по подписанному манифесту перед установкой.
- Автоматизация релизов и CI: workflow-ы GitHub содержат Windows CI (windows-tests) и релиз-пайплайны, проверяющие формат тега и требующие успешного main CI; при наличии секрета сборки создаются подписанные пакеты, запускаются сканы VirusTotal (требуется VIRUSTOTAL_API_KEY) и сохраняются частичные отчёты; prepare-release может генерировать черновые заметки на английском и русском при наличии OPENAI_API_KEY.
- Инструменты сборки и оболочки: добавлены обёртки-скрипты (build.cmd, build-installer.cmd, install.cmd, scripts\tools.cmd и др.) и команды CI для тестов (engine/h3/ui/ssh), которые ожиданы в Windows CI на runners windows-2025 с uv/python и .NET SDK.
- Импорт/экспорт и ограничения: GUI поддерживает импорт/экспорт MegaProxy JSON v1–8 и распространённых списков прокси, по умолчанию исключает пароли/ключи и применяет пользовательские ограничения (до 1 000 профилей/правил, локальные настройки ≤8 MiB, экспорт ≤4 MiB, приватный ключ ≤64 KiB).
- Сетевые возможности и ограничения: поддерживаются HTTPS, SOCKS5, MASQUE (требует HTTP/3) и SSH (только TCP); HTTP/3 помечен как экспериментальный и скрывается при отсутствии поддержки, MASQUE работает только через QUIC/HTTP/3, а SSH Jump и ключи с passphrase на Windows пока не поддерживаются.
- Активы и локализация: добавлены русские строки интерфейса (assets/strings.json), палитра цветов профилей, 257 записей флагов стран, SVG-иконки/брендирование и публичный ключ обновлений в assets/update-public-key.txt для закрепления ключа обновлятора.
- Тестирование и smoke-проверки: добавлены юнит/интеграционные/UI тесты и smoke-скрипты (tests/WindowsMegaProxy.UiChecks, installer_smoke.py, dev_mode_smoke.py) и загрузка артефактов CI (скриншоты, логи, отчёты); многие smoke-тесты намеренно не активируют TUN/драйверы и полную проверку драйвера/инсталляции следует выполнять в disposable Windows VM.

# v0.0.1

## English

First Windows preview: native English/Russian interface, proxy profiles,
application and destination rules, shared background service, connection
monitoring, diagnostics and rotating logs. Includes an x64 installer, stable
and experimental HTTP/3 cores, and signed manifests for future updates.

HTTP/3 remains experimental. The installer is not Authenticode-signed.

## Русский

Первая предварительная версия для Windows: нативный интерфейс на английском
и русском, профили прокси, правила по приложениям и назначениям, общая фоновая
служба, мониторинг соединений, диагностика и ротация логов. Добавлены установщик
x64, стабильное и экспериментальное HTTP/3 ядра и подписанные манифесты для
будущих обновлений.

HTTP/3 остаётся экспериментальным. Установщик не имеет подписи Authenticode.

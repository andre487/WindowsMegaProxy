# v0.0.11

## English

- Fixed the missing tray client in service mode: it now starts minimized to the notification area when a user signs in to Windows.
- Opening MegaProxy again shows the existing client window. Exiting the client leaves the service running.

## Русский

- Исправлен запуск клиента в режиме службы: теперь при входе пользователя в Windows он автоматически запускается свёрнутым в трей.
- Повторный запуск MegaProxy открывает уже работающий клиент. Выход из клиента не останавливает службу.

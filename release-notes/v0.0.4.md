# v0.0.4

## English

- The installer and application archive now include .NET 10.0.14 and both checksum-pinned sing-box cores: stable 1.14.4 and 1.15.0-alpha.13 for HTTP/3. Application executables are self-contained single-file builds; no separate .NET or WinGet installation is required.
- Profiles select the appropriate core automatically. The global HTTP/3 enable switch and on-demand core download have been removed; obsolete switches in imported configurations are ignored.
- Windows OpenSSH Client is a mandatory prerequisite. Setup installs the Windows capability when missing and reports installation failures instead of continuing with an incomplete installation.
- Machine and current-user installation, manual startup, login startup and system-service modes remain available. DEV uses a separate identity and keeps its service runtime isolated from the desktop application's runtime files.
- Release packages retain Authenticode signatures, signed update manifests and checksum verification. Antivirus scanning is now an optional local diagnostic via `check-virus-total.cmd`; reports are not included in releases. Isolated antivirus false positives remain possible, including for the bundled upstream sing-box binaries.

## Русский

- Установщик и архив приложения теперь содержат .NET 10.0.14 и оба ядра sing-box с закреплёнными контрольными суммами: стабильное 1.14.4 и 1.15.0-alpha.13 для HTTP/3. Исполняемые файлы собираются как self-contained single-file; отдельная установка .NET и WinGet не нужна.
- Ядро выбирается автоматически по транспорту профиля. Удалены общий переключатель HTTP/3 и загрузка ядра по запросу; устаревшие переключатели в импортируемых конфигурациях игнорируются.
- Windows OpenSSH Client стал обязательной зависимостью. При его отсутствии установщик добавляет компонент Windows; при ошибке установка останавливается с сообщением.
- Сохранены установка для системы и текущего пользователя, ручной запуск, запуск при входе и режим системной службы. DEV имеет отдельную идентичность, а runtime службы изолирован от файлов runtime интерфейса.
- Сохранены подписи Authenticode, подписанный манифест обновления и проверка контрольных сумм. Проверка антивирусами доступна вручную через `check-virus-total.cmd`; отчёты не входят в релиз. Возможны единичные ложные срабатывания, в том числе на включённые официальные бинарные файлы sing-box.

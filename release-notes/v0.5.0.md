# v0.5.0

## English

- Added a coreLogLevel setting and UI control to choose the sing-box log level (trace, debug, info, warn, error, fatal, panic); defaults to "warn", is validated on import/export, saved to settings, and takes effect after reconnecting (debug/trace are more verbose and include destination addresses and application paths).

- Profile DNS now applies to ordinary application DNS while an active profile is connected, so applications routed directly still use the active profile's DNS through the proxy; disconnecting restores system DNS and application-managed DoH is unaffected.

- Bootstrap DNS resolves proxy hostnames before connecting and the "auto" bootstrap provider now selects Cloudflare; bootstrap does not replace application-managed DoH and disconnecting removes the TUN DNS configuration so system DNS resumes.

- The runtime clears the Windows DNS resolver cache when TUN DNS is activated and again on TUN shutdown and logs success or the Win32 error code if the flush fails, to reduce stale system DNS entries (applications with their own caches may still need restart).

- The network core detects whether an IPv6 uplink is available and, when none is found, removes the TUN IPv6 address, sets DNS strategy to ipv4_only and injects a route rule that rejects IPv6 traffic; when an IPv6 uplink is present the TUN remains dual‑stack.

- The generated core configuration uses the configured coreLogLevel for sing-box logging and validation rejects invalid log level strings to avoid producing invalid core configs.

- Settings import/export and the portable settings format include coreLogLevel so the choice round-trips and is considered by network-change analysis (changing the log level requires reconnection to apply).

- Installer/update test tooling: upgrade checks now seed fixtures using the installed release's settings defaults to avoid compatibility problems with newer project defaults, and service commands invoked during update checks capture and print redirected stdout for diagnostics.

## Русский

- Добавлено поле coreLogLevel и элемент управления в интерфейсе для выбора уровня логов sing-box (trace, debug, info, warn, error, fatal, panic); значение по умолчанию — «warn», значение проверяется при импорте/экспорте, сохраняется в настройках и применяется после переподключения (debug/trace более подробные и включают адреса назначения и пути приложений).

- DNS профиля теперь применяется ко всем обычным DNS-запросам приложений при подключённом активном профиле, поэтому приложения с прямым маршрутом будут использовать DNS профиля через прокси; при отключении восстанавливается системный DNS, DoH, управляемый приложением, не затрагивается.

- Bootstrap DNS разрешает имена прокси до подключения, а значение "auto" теперь выбирает Cloudflare; bootstrap не заменяет DoH приложений, а отключение удаляет настройку DNS туннеля и возвращает системный DNS.

- Во время активации DNS туннеля и при его завершении приложение вызывает очистку кеша DNS Windows и логирует успех или код ошибки Win32 при неудаче, чтобы снизить вероятность устаревших записей (приложения с собственным кешем могут требовать перезапуска).

- Ядро сети определяет наличие IPv6‑uplink и при его отсутствии удаляет IPv6‑адрес туннеля, переключает стратегию DNS на ipv4_only и добавляет правило маршрутизации, отклоняющее IPv6‑трафик; при наличии IPv6‑uplink туннель остаётся двойным стеком.

- Сгенерированная конфигурация ядра использует coreLogLevel для уровня логов sing-box, а некорректные значения уровня логов отвергаются на этапе валидации, чтобы не создавать недопустимый конфиг ядра.

- Импорт/экспорт настроек и переносимый формат включают coreLogLevel, выбор корректно сохраняется и учитывается при анализе изменения сети (смена уровня логов требует переподключения для применения).

- Средства проверки обновлений/инсталлятора: проверки обновления теперь формируют тестовые фикстуры из настроек установленного релиза, чтобы избежать несовместимости с новыми дефолтами проекта; команды сервиса, выполняемые в проверках, захватывают и печатают перенаправленный stdout для диагностики.

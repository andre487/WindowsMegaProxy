# v0.0.8

## English

- Hover over the system tray icon to see the active connection profile and transport. Selecting a different profile keeps the current connection details until reconnecting.
- The main window now shows the transport below the connection status: HTTP/1.1, HTTP/3 over QUIC, SOCKS5 or SSH. Unavailable negotiation details are omitted.
- HTTP/3 fallback displays HTTP/1.1. Connection details refresh when the active connection changes and clear from the tray and transport line after disconnection or loss of the service.
- Long profile names fit the Windows tray tooltip while keeping the protocol visible.

## Русский

- При наведении на значок в трее показываются активный профиль подключения и транспорт. Выбор другого профиля не меняет сведения о текущем подключении до переподключения.
- Под статусом подключения в главном окне теперь отображается транспорт: HTTP/1.1, HTTP/3 через QUIC, SOCKS5 или SSH. Недоступные сведения о согласовании не показываются.
- При переходе с HTTP/3 на TCP отображается HTTP/1.1. Сведения обновляются при изменении активного подключения и исчезают из трея и строки транспорта после отключения или потери связи со службой.
- Длинные имена профилей сокращаются под размер подсказки Windows, сохраняя видимым протокол.

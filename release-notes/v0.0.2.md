# v0.0.2

## English

- Native Windows preview client and installer for Windows 10/11 x64: installer (Inno Setup) targets Program Files by default and supports system-wide (service) or current-user installs with separate protected locations for DEV and production.

## Русский

- Нативный Windows-превью-клиент и установщик для Windows 10/11 x64: Inno Setup‑инсталлятор по умолчанию устанавливается в Program Files и поддерживает системную установку (сервис) или установку для текущего пользователя с отдельными защищёнными каталогами для DEV и production.

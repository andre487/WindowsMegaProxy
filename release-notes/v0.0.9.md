# v0.0.9

## English

- Standalone applications can update now or defer installation until the next application start.
- Service installations can update now, restart the computer and update, or update at the next computer restart. The immediate option explains that connections use system network settings while the service is updating.
- Deferred updates preserve the current session. Settings show the scheduled update and let you change its timing.
- Updates are prepared in a protected temporary directory and verified again before installation. An isolated updater releases application files for replacement, restores service startup and cleans up temporary files.
- Next-start updates also work for personal installations through their scheduled launcher. Update helpers do not open console windows.

The new timing choices become available after installing this version. Updating to 0.0.9 uses the update mechanism in your currently installed version.

## Русский

- При запуске обычным приложением можно обновиться сейчас или при следующем запуске приложения.
- В режиме службы можно обновиться сейчас, перезагрузить компьютер и обновиться либо обновиться при следующей перезагрузке. У немедленного обновления есть пояснение: на время обновления службы соединения будут использовать системные настройки сети.
- При откладывании обновления текущий сеанс сохраняется. В настройках отображается запланированное обновление и можно изменить время установки.
- Обновление подготавливается в защищённом временном каталоге и повторно проверяется перед установкой. Отдельный помощник освобождает файлы приложения для замены, восстанавливает запуск службы и очищает временные файлы.
- Обновление при следующем запуске работает и для персональной установки через её штатный launcher. Помощники обновления не открывают консольных окон.

Новые варианты времени установки станут доступны после установки этой версии. Переход на 0.0.9 выполняется механизмом обновления текущей установленной версии.

# v0.3.2

## English

- Fixed personal installation failing under UAC while creating the application launcher folder. User-file operations now use a restricted token of the installing user with administrator privileges removed and medium integrity.
- Fixed personal uninstall reading its protected repair inventory after dropping privileges. The inventory is now read first; user files are still deleted with restricted rights and path checks remain in place.
- Added regression tests for restricted file operations, user identity, administrator-right removal and restoring the caller's token after errors. CI installation and removal scenarios now exercise restricted operations even on runners without split UAC tokens.

## Русский

- Исправлен сбой персональной установки при включённом UAC во время создания папки запуска приложения. Операции с пользовательскими файлами теперь выполняются с ограниченным токеном того же пользователя, без административных привилегий и с обычным уровнем целостности.
- Исправлено чтение защищённого списка файлов при удалении персональной установки: список считывается до понижения прав. Пользовательские файлы по-прежнему удаляются с ограниченными правами; проверки путей сохранены.
- Добавлены тесты файловых операций с ограниченными правами, сохранения личности пользователя, отсутствия прав администратора и восстановления исходного токена после ошибок. Сценарии установки и удаления в CI теперь проверяют ограниченные операции и на машинах без разделённых UAC-токенов.

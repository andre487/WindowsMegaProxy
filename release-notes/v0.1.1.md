# v0.1.1

## English

- Added a permanent download asset named "WindowsMegaProxy-setup.exe" to releases starting with 0.1.1 so users can use a stable latest/download permalink.
- The permanent asset is uploaded as a byte-for-byte copy of the versioned installer verified against the signed update manifest and keeps the same SHA-256, so the permalink is not a separate build.
- Release tooling now copies the verified versioned installer to the permanent filename and uploads that alias while the release is still a draft, ensuring the latest/download redirect serves the verified bytes.
- Added bilingual (English/Russian) user documentation, including Installation, Profiles & routing, Application updates, Screenshots, Antivirus/Signing and Development guides.
- Installation documentation now states the bundled installer includes .NET and both proxy cores and will prepare Windows OpenSSH if missing, and that the installer uses a persistent self-signed signature which may trigger SmartScreen or antivirus warnings.
- The Updates guide documents the permanent installer permalink, the option to download updates through the connected proxy, and installation timing choices (install now or defer; service install timing options).
- Publisher tests and scripts were added to verify and enforce that the uploaded permanent-name installer matches the verified installer bytes.
- Application runtime behavior is unchanged by this release; the changes are documentation and release/publishing tooling only.

## Русский

- В релизах, начиная с 0.1.1, добавлен постоянный файл установки с именем "WindowsMegaProxy-setup.exe", доступный по стабильной ссылке latest/download.
- Этот постоянный файл загружается как побайтовая копия версионного установщика, проверенного по подписанному манифесту, и имеет тот же SHA-256, поэтому ссылка latest/download не является отдельной сборкой.
- Инструменты публикации теперь копируют проверенный версионный установщик в файл с постоянным именем и загружают этот псевдоним ещё на этапе draft, чтобы redirect latest/download отдавал проверенные байты.
- Добавлена двуязычная (английская и русская) документация для пользователей: Установка, Профили и маршрутизация, Обновления приложения, Скриншоты, Антивирус/Подпись и Руководство для разработчиков.
- В документации по установке указано, что инсталлятор комплектует .NET и оба ядра прокси и при необходимости подготовит Windows OpenSSH, а также что установщик подписан постоянным самоподписанным сертификатом, из‑за которого SmartScreen или антивирусы могут показывать предупреждения.
- В руководстве по обновлениям описана постоянная ссылка на установщик, опция загрузки обновлений через подключённый прокси и варианты установки (сейчас или отложенно; варианты для службы Windows).
- В скрипты публикации и тесты добавлена проверка и привязка, гарантирующая, что загружаемый файл с постоянным именем совпадает с проверенным установщиком по байтам.
- Поведение приложения во время выполнения не изменилось в этом релизе: изменения касаются только документации и инструментов публикации/релиза.

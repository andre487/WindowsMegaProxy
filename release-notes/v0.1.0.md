# v0.1.0

## English

- Opt-in IPv4 TCP reset: new ResetExistingTcpConnections setting captures candidate IPv4 (non-loopback) sockets before launching the core and attempts to close matching connections after the core becomes responsive, skipping loopback, listed DirectProcessNames, LAN-bypass addresses and ambiguous domain rules; failures are logged and the operation may interrupt downloads or require privileges.
- ExistingTcpConnections behavior: only IPv4 (no IPv6), closes sockets selected by EXE/folder rule matches routed through the active profile, verifies process start time before closing, and safe-fails on Win32/IO errors.
- Core diagnostics made cancellable and lighter: GetConnectionsAsync now accepts a CancellationToken and the Engine applies a short (≈2s) deadline and streams JsonDocument parsing, so long core reads can time out or be cancelled instead of blocking the UI.
- Connection snapshot/backoff policy: ConnectionSnapshot parsing now uses JsonElement, caps displayed rows at 1000 while preserving the Total counter and large byte totals, and exposes PollInterval(total) so the UI slows polling (e.g., 2s/5s) when total connections are large, reducing polling overhead.
- ServiceBroker reader cancellation: long-running "connections" and "http3" reads no longer hold the network gate while awaiting I/O and are tracked/cancelled by StopAsync, so stopping or restarting the core cancels in-flight reads and improves responsiveness.
- Notification and dialog UX changes: the app attempts to register an AppUserModelID and an icon file for Windows notifications on startup (non-fatal on IO/registry failures), and MessageDialog replaces many MessageBox calls to unify confirmations and error dialogs and inherit localization/theme.
- Tray, settings and profiles UX: tray tooltip shows connection state immediately (e.g., "Checking…"/"Connecting…"/running profile), AlwaysMinimizeToTray hides the window when minimized if enabled, profile items show a TypeLabel and Endpoint, and drag-and-drop profile reordering persists order via CommitSettingsAsync.
- IPv6 CI and tests added: a new ipv6-test.cmd, scripts/ssh_test.py IPv6 support and multiple Ipv6Checks/Ipv6UiChecks were added to CI and tests to exercise IPv6 loopback routing across proxy types using pinned sing-box cores and local fixtures; these changes affect test coverage/CI only and require IPv6 loopback plus the pinned cores to run.
- Test fixture/behavioral changes: test helpers expose cancellable Http3/Connections delegates, numerous UI tests updated to stricter layout, polling and cancellation expectations, and some UI elements/strings were adjusted (localized strings added), so test runners may need the updated binaries and locale support to pass.

## Русский

- Сброс существующих IPv4‑соединений по выбору: новая настройка ResetExistingTcpConnections собирает кандидатов для закрытия до запуска ядра и пытается разорвать соответствующие IPv4 (не loopback) соединения после того, как ядро ответит; loopback, процессы из DirectProcessNames, LAN‑адреса и неоднозначные правила доменов пропускаются, ошибки логируются, операция может прервать загрузки и требовать прав.
- Поведение ExistingTcpConnections: только IPv4 (без IPv6), закрываются только сокеты, выбранные по правилам EXE/папка и маршрутизируемые через активный профиль, перед закрытием проверяется время запуска процесса, и при Win32/IO‑ошибках выполняется безопасное завершение.
- Диагностика ядра стала отменяемой и легче: GetConnectionsAsync принимает CancellationToken, Engine применяет короткий тайм‑аут (~2 с) и парсит ответ потоково через JsonDocument, поэтому долгие запросы к ядру могут отменяться вместо блокировки UI.
- Снимок соединений и политика паузы: ConnectionSnapshot теперь парсит JsonElement, ограничивает отображаемые строки до 1000 при сохранении общего счёта Total и больших сумм байт, а PollInterval(total) позволяет UI замедлять опрос (например, 2 с / 5 с) при большом числе соединений для снижения нагрузки.
- Отмена чтения в ServiceBroker: длительные чтения "connections" и "http3" больше не удерживают сетевой семафор при ожидании I/O и отслеживаются/отменяются StopAsync, поэтому остановка или перезапуск ядра прерывает незавершённые запросы и повышает отзывчивость.
- Уведомления и диалоги: приложение пытается зарегистрировать AppUserModelID и файл иконки для уведомлений Windows при запуске (сбоев в реестре/IO не считается фатальными), а MessageDialog заменяет многие MessageBox для унифицированных подтверждений и ошибок с учётом локализации/темы.
- UX трей/настроек/профилей: трей показывает состояние соединения сразу (например, "Checking…"/"Connecting…"/активный профиль), AlwaysMinimizeToTray скрывает окно при сворачивании, профиль отображает TypeLabel и Endpoint, а перетаскивание профилей сохраняет порядок через CommitSettingsAsync.
- IPv6 в CI и тестах: добавлены ipv6-test.cmd, поддержка IPv6 в scripts/ssh_test.py и наборы Ipv6Checks/Ipv6UiChecks для проверки локального IPv6‑loopback‑маршрута по всем типам прокси с привязанными sing-box бинарями; эти изменения относятся к CI/тестам и требуют поддержки IPv6 loopback и локальных бинарей для запуска.
- Изменения в тестовом стенде: фикстура тестов предоставляет отменяемые делегаты Http3/Connections, многие UI‑тесты уточнены по верстке, опросу и отмене, добавлены/изменены строки локализации, поэтому для успешного прогона тестов может потребоваться обновлённая сборка и поддержка локалей.

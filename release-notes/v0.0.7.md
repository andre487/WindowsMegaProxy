# v0.0.7

## English

- MegaProxy now exits after handing an update to the installer, releasing the application files for replacement.
- Repeated clicks on Install Update no longer launch additional installers.
- Failed update helpers exit promptly and record the reason in the application log instead of leaving a hidden error dialog that locks application files.
- An update that fails before copying its installer preserves the previously staged installer. Cleanup failures no longer hide the original error.

When upgrading from 0.0.6 or earlier after a failed update attempt, restart Windows to release any stuck update helpers, then download and run this installer manually. Your settings are preserved.

## Русский

- MegaProxy теперь завершает работу после передачи обновления установщику, освобождая файлы приложения для замены.
- Повторные нажатия «Установить обновление» больше не запускают дополнительные установщики.
- При ошибке помощник обновления быстро завершается и записывает причину в журнал приложения вместо скрытого окна ошибки, удерживающего файлы.
- Если ошибка произошла до копирования установщика, ранее подготовленный установщик сохраняется. Ошибки очистки больше не скрывают исходную причину сбоя.

При переходе с 0.0.6 или более ранней версии после неудачной попытки обновления перезагрузите Windows, чтобы завершить зависшие помощники обновления, затем скачайте и запустите этот установщик вручную. Настройки сохранятся.

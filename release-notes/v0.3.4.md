# v0.3.4

## English

- When updating an existing installation, “Launch MegaProxy” is enabled by default if the client was running when setup started. You can still turn it off.
- Release installers and application ZIPs are scanned with VirusTotal before publication. Up to 10 combined malicious/suspicious verdicts per file are allowed; more detections or an incomplete or failed scan stop publication.
- Release notes include detection counts and links to VirusTotal reports. When detections are present, an explanation of possible false positives for lesser-known proxy software is included. Raw reports are not attached to the release.

## Русский

- При обновлении установленного приложения опция «Запустить MegaProxy» включается по умолчанию, если клиент работал на момент запуска установщика. Её по-прежнему можно отключить.
- Установщик и ZIP с приложением проходят проверку VirusTotal перед публикацией. Допускается до 10 суммарных срабатываний malicious/suspicious на каждый файл; превышение порога, ошибка или неполный результат проверки останавливают публикацию.
- В описание релиза добавляются количество срабатываний и ссылки на отчёты VirusTotal. При наличии срабатываний выводится пояснение о возможных ложных срабатываниях на малоизвестное ПО для работы с прокси. Файлы отчётов к релизу не прикладываются.

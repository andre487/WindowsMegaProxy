# v0.0.12

## English

- Fixed a missing tray client when a Windows sign-in overlaps an application update after restarting the computer. The client is restored in the signed-in user's session after installation completes.
- When another MegaProxy version is running, a client started in the tray now shows a notification asking you to choose which version to keep. Click the notification or open MegaProxy to make the choice.

## Русский

- Исправлено отсутствие клиента в трее, если вход в Windows совпал с установкой обновления после перезагрузки. После завершения установки клиент запускается в сессии вошедшего пользователя.
- Если работает другая версия MegaProxy, клиент, запущенный в трее, показывает уведомление с предложением выбрать версию. Нажмите на уведомление или откройте MegaProxy, чтобы сделать выбор.

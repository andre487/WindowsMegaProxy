WindowsMegaProxy distribution

Application: MIT. Source: https://github.com/andre487/WindowsMegaProxy
Application source for this build is supplied as a separate release archive.

BouncyCastle.Cryptography 2.7.0 verifies Ed25519 update signatures on Windows 10/11.
Source: https://github.com/bcgit/bc-csharp/tree/release-2.7.0
License: licenses/BouncyCastle-LICENSE.md.

sing-box: GPL-3.0-or-later. Each core directory includes its upstream license.
The complete GPL-3.0 text is included in licenses/GPL-3.0.txt.
Stable source: https://github.com/SagerNet/sing-box/tree/v1.14.4
HTTP/3 source: https://github.com/SagerNet/sing-box/tree/v1.15.0-alpha.13
Releases: https://github.com/SagerNet/sing-box/releases
Build metadata and upstream dependencies: run sing-box.exe version -m.
Stable sing-box is installed through WinGet. An optional HTTP/3 core is downloaded
only when needed, after confirmation, and checked against pinned SHA-256 hashes.
Cronet (libcronet.dll) is installed unmodified from those packages.
Cronet-Go source: https://github.com/SagerNet/cronet-go/tree/0d28acc44093
Cronet-Go license: licenses/Cronet-Go-LICENSE.txt.
Chromium license and third-party notices: https://www.chromium.org/chromium-os/licenses/

Wintun is embedded in the upstream cores. The signed upstream binary is used;
WindowsMegaProxy does not build a kernel driver or remove the shared driver.
Wintun: https://www.wintun.net/ and https://git.zx2c4.com/wintun/
The Wintun binary distribution license is included in licenses/Wintun-LICENSE.txt.

.NET Desktop Runtime is installed through WinGet from Microsoft, not bundled.
Windows OpenSSH Client is an optional Windows capability, not bundled.
Their respective installers and operating-system license terms apply.

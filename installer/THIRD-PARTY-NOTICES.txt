WindowsMegaProxy distribution

Application: GPL-3.0-or-later. See LICENSE.txt.
Original setup code: MIT. See licenses/Setup-MIT.txt and LICENSING.md for scopes.
Source: https://github.com/andre487/WindowsMegaProxy
Application source for this build is supplied as a separate release archive.
The MIT notice for previously MIT-licensed project code is preserved in
licenses/WindowsMegaProxy-MIT.txt. Earlier MIT releases retain their original license.

BouncyCastle.Cryptography 2.7.0 verifies Ed25519 update signatures on Windows 10/11.
Source: https://github.com/bcgit/bc-csharp/tree/release-2.7.0
License: licenses/BouncyCastle-LICENSE.md.

sing-box: GPL-3.0-or-later. Each core directory includes Core-NOTICES.txt with
the licenses of its embedded dependencies. MegaProxy builds its own DLLs from
the pinned upstream modules; these are not official sing-box release binaries.
The complete GPL-3.0 text is included in licenses/GPL-3.0.txt.
Stable source: https://github.com/SagerNet/sing-box/tree/v1.14.4
HTTP/3 source: https://github.com/SagerNet/sing-box/tree/v1.15.0-alpha.13
Releases: https://github.com/SagerNet/sing-box/releases
Build metadata: native/core/go.mod, native/core/experimental.mod and their checksums.
The profile transport selects the DLL automatically. Each DLL contains its own Go runtime.

The diagnostic helper is GPL-3.0-or-later; its dependency notices are in
Notices/Diagnostics-NOTICES.txt. Country flags: MIT, Notices/flag-icons-LICENSE.txt.
MegaProxy artwork: CC0-1.0, licenses/Artwork-CC0.txt.

Wintun is embedded in the upstream cores. The signed upstream binary is used;
WindowsMegaProxy does not build a kernel driver or remove the shared driver.
Wintun: https://www.wintun.net/ and https://git.zx2c4.com/wintun/
The Wintun binary distribution license is included in licenses/Wintun-LICENSE.txt.

.NET 10.0.14 is downloaded from official Microsoft packages on NuGet.org and installed beside the application.
.NET source and license: https://github.com/dotnet/runtime/tree/v10.0.14
Windows OpenSSH Client is a mandatory Windows capability installed when missing.
Their respective installers and operating-system license terms apply.

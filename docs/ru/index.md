# Документация MegaProxy для Windows

[English](../en/index.md) · [Главная](../../README.md)

MegaProxy направляет приложения через серверы, которыми вы управляете или которым
доверяете. Серверы и учётные данные не предоставляются.
Настройка сервера: [MegaProxyServer](https://github.com/andre487/MegaProxyServer).

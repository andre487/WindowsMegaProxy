# Установка

[English](../en/installation.md) · [Документация](index.md)

**[Скачать установщик MegaProxy](https://github.com/andre487/WindowsMegaProxy/releases/latest/download/WindowsMegaProxy-setup.exe)**

Нужны Windows 10/11 x64 и учётная запись администратора. При установке и настройке
привилегированного запуска Windows может запросить подтверждение UAC.
Оба прокси-ядра входят в комплект. Если нужная версия .NET отсутствует, повреждена
или требует обновления, установщик скачивает пакеты Microsoft с NuGet.org и размещает
.NET рядом с MegaProxy. Python, Go, uv и .NET SDK пользователю не нужны. Если Windows OpenSSH Client отсутствует, установщик добавит его.

Установщик подписан постоянным самоподписанным сертификатом, который не устанавливает
доверие издателю в Windows. Возможны предупреждения SmartScreen или антивируса.
Подробнее: [подпись и антивирусы](../ANTIVIRUS.md).

## Область установки и запуск

| Область | Конфигурация | Режимы |
| --- | --- | --- |
| Для системы | Общая, редактируется администраторами | Вручную, при входе, служба Windows |
| Для пользователя | Личная, с зашифрованными параметрами | Вручную или при входе; без службы |

Системная версия устанавливается в Program Files, персональная — в каталог
приложений пользователя. При обновлении сохраняйте выбранную область.
В режиме службы администраторы могут менять общие настройки, остальные пользователи
видят интерфейс только для чтения. При входе запускается клиент в трее;
служба может поддерживать подключение независимо от окна.

В ручном режиме перехват начинается после подключения приложения. Режим входа
запускает приложение автоматически. Установщик подготавливает защищённый запуск
с нужными правами. В дальнейшем режим можно изменить в настройках.

Для текущего пользователя одновременно регистрируется одна область установки.
Для смены области сначала удалите приложение; конфигурация сохранится.

## Первое подключение

1. Добавьте профиль или импортируйте конфигурацию в настройках.
2. Выберите маршрут по умолчанию. Изначально выбран системный; правила задают исключения.
3. Выберите активный профиль и подключитесь.
4. Откройте проверку соединения, затем при необходимости измерьте скорость.

Закрытие окна обычно оставляет MegaProxy в трее. Для выхода используйте меню
значка или кнопку в настройках. Отдельно работающая служба продолжает работу,
пока вы не отключите соединение или не остановите службу.

См. [Обновления](updates.md). Удаление доступно через **Параметры Windows →
Приложения** или список установленных программ в Панели управления.

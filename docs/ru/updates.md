# Обновления приложения

[English](../en/updates.md) · [Документация](index.md)

По умолчанию MegaProxy проверяет GitHub Releases раз в день. Автопроверку можно
отключить; кнопка «Проверить сейчас» доступна в разделе обновления приложения.
Проверка и загрузка — отдельные действия. Ссылка на релиз открывает список
изменений на GitHub.

Опция загрузки через прокси относится и к проверке, и к скачиванию.
Для неё сначала подключитесь. На диске хранится не более одного скачанного
обновления. Перед установкой проверяются подписанный манифест и хеш пакета.

| Режим | Варианты установки |
| --- | --- |
| Приложение | Сейчас или при следующем запуске приложения |
| Служба Windows | Сейчас без перезагрузки, при следующей загрузке компьютера или с перезагрузкой сейчас |

Установка сейчас временно прерывает работу прокси: соединения пойдут по системному
маршруту. При отложенной установке до выбранного события работает текущая версия.
Обновление службы при загрузке выполняется до запуска обновлённой службы.

## Постоянная ссылка

Для публикаций и закладок используйте ссылку без номера версии:

**[WindowsMegaProxy-setup.exe](https://github.com/andre487/WindowsMegaProxy/releases/latest/download/WindowsMegaProxy-setup.exe)**

Ссылка ведёт на последний опубликованный релиз. Для фиксированной версии используйте файл
из [конкретного релиза](https://github.com/andre487/WindowsMegaProxy/releases).

Если обновление из приложения недоступно, скачайте Setup и установите поверх
существующей версии WiX/Burn с той же областью установки. Профили и настройки сохранятся.
Однократный переход с Inno Setup описан в [руководстве установки](installation.md).

# Профили и маршрутизация

[English](../en/profiles-and-routing.md) · [Документация](index.md)

## Типы профилей

| Тип | Транспорт и ограничения |
| --- | --- |
| HTTPS | CONNECT через HTTP/1.1; дополнительно HTTP/2 или HTTP/2 + HTTP/3 |
| HTTPS с Jump | Два HTTPS-прокси; для H3 нужна поддержка на обоих хопах |
| SOCKS5 | TCP и UDP ASSOCIATE; транспорт не шифруется |
| SSH | TCP, пароль или закрытый ключ |
| SSH с Jump | Два SSH-хопа с общими или отдельными учётными данными |
| MASQUE α | Экспериментальный HTTP/3 для TCP и UDP |

HTTP/1.1 использует комплектное стабильное ядро, HTTP/2 и HTTP/3 — альфа-ядро.
Выбор версии HTTP допускает поддерживаемый переход на более низкую версию.
Ошибки сертификата или авторизации не должны приводить к прямому обходу прокси.
Ключи SSH-серверов принимаются без проверки. Закрытые ключи SSH с парольной фразой
не поддерживаются.

У профилей есть названия, флаги и цвета; порядок меняется перетаскиванием.
Изменения активного подключения применяются после переподключения.
Статус показывает применённый профиль, даже если в списке выбран другой.

## Правила и IPv6

Правила поддерживают EXE-файлы, папки с рекурсией, домены, доменные маски,
IP-адреса, подсети и списки Podkop. Действия: активный профиль, системный маршрут
или блокировка. Галочка отключает правило без удаления.

Опция IPv6 ограничивает адреса назначения через профиль, а не IPv6 в Windows
и не адрес самого прокси. Явные системные правила и обход локальной сети сохраняют
своё поведение. SSH и HTTPS только через TCP не предоставляют пересылку UDP.

Списки Podkop можно обновлять через подключённый прокси. Тогда при запуске
используется кеш, а загрузка выполняется после подключения.

## DNS и параметры подключения

DNS профиля поддерживает Cloudflare, Google, Quad9, Yandex, собственный DoH
и TCP/UDP-серверы. Когда профиль — маршрут по умолчанию, его DNS идёт через прокси;
системный режим сохраняет DNS Windows. Для UDP DNS нужен совместимый транспорт,
прямого резервного маршрута нет. Query-параметры в DNS URL не поддерживаются.

Bootstrap DNS разрешает имя прокси до подключения через DNS Windows или выбранный
DoH напрямую. Доступны TCP TLS и SSH fingerprint; для H3 используется штатный
fingerprint ядра.

## Конфигурации, подписки и диагностика

Импорт: MegaProxy JSON v1–8, FoxyProxy JSON, ProxyList и SuperProxy.
Экспорт: MegaProxy JSON или ProxyList. При импорте можно выбрать параметры;
отсутствующие опции не меняют текущие значения, опции других платформ сохраняются.
Пароли и закрытые ключи по умолчанию не экспортируются. Файл экспорта не шифруется.

HTTPS-подписки поддерживают резервные адреса и Basic-аутентификацию.
Обновления сохраняют локальные профили; для применения сетевых изменений нужно
переподключиться. Резервирование использует выбранные или все профили в порядке списка.

При открытии проверки начинается тест соединения; после успеха доступен тест
скорости. H3 проверяется для совместимых транспортов. Репутация выходного IP
из ProxyCheck не гарантирует анонимность.

Во вкладке соединений доступны группы и скорость передачи. «Показывать всё»
включает соединения маршрута по умолчанию. Пути и фрагменты журнала можно копировать.
Журналы хранятся локально, ротируются с заданным ограничением размера
и содержат сообщения на английском.
